Product provenance and time interpretation

Use the valid time printed on the source map. NASA SPoRT is a blended composite, not an instantaneous observation. Retrieval and HTTP modification times are not observation times. NASA anomaly maps are labeled SPoRT Composite/MERRA2 (1991–2020); NOAA anomalies use CoralTemp’s 1991–2020 climatology. These are distinct products. This SST layer is separate from CPC’s ERSST-based RONI index and is not an input to the Q3 model.
